# Scenario 003: Quality versus Launch Date

A customer-visible release is due Friday. Core behaviour passes, but restore has not been exercised, one authorization
contract test is flaky, and the rollback path assumes a backward-compatible schema that has not been proved.

Explain how you classify the risks, which work blocks launch, what scope or exposure alternatives exist, who accepts any
remaining risk, and how temporary mitigations receive owners and expiry.
