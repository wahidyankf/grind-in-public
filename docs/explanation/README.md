# Explanation

Explanation provides understanding: background, rationale, trade-offs, and connections between ideas in Grind in Public.

Write explanation when the reader asks, “Why is this designed or practiced this way?” Discuss the subject rather than
directing a task. Link to tutorials, how-to guides, or reference material when readers also need action or facts.
