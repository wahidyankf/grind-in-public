# Done

Completed plans, named `YYYY-MM-DD__<identifier>/` using the date the final commit landed. They are history, not
documentation, and their value comes from being accurate rather than tidy — including about what went badly.

Do not casually rewrite an archived plan. If a defect surfaces later, reopen it: move the folder back to
[`in-progress/`](../in-progress/README.md), strip the date prefix, and add a dated note explaining what broke.
