# Ideas

Two-pager briefs, one `<slug>.md` file in the urgency-and-importance quadrant supported by dated evidence. An idea argues that a problem is worth solving; it does not design the solution. A ripe idea is promoted into a full plan in [`backlog/`](../backlog/README.md).

See the [two-pager template](../../repo-governance/conventions/plans-organization-policy/two-pager-template.md) for the eight required sections.

## Directory Map

- [Q1: Urgent and Important](q1-urgent-important/README.md) — act first when evidence supports both dimensions.
- [Q2: Not Urgent and Important](q2-not-urgent-important/README.md) — schedule deliberately before urgency grows.
- [Q3: Urgent and Not Important](q3-urgent-not-important/README.md) — constrain, delegate, or discard when possible.
- [Q4: Not Urgent and Not Important](q4-not-urgent-not-important/README.md) — defer unless evidence changes.
