# Applications

This directory contains runnable workspace applications. Each application owns its source, tests, project configuration, and application-specific documentation; shared packages belong in [`libs/`](../libs/README.md).

## Current Applications

- [`badakmini-cli`](badakmini-cli/README.md) — the standard-library Go CLI that implements repository-local validation checks.
- [`wahidyankf-www`](wahidyankf-www/README.md) — the Next.js personal site, holding the repository's single authoritative CV record.
- [`wahidyankf-www-e2e`](wahidyankf-www-e2e/README.md) — the dedicated Playwright suite that drives `wahidyankf-www` in a real browser.
