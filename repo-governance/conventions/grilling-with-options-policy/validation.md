# Validation

The [grilling-with-options policy](../grilling-with-options-policy.md) owns the rules. This is the pass over a drafted
question, run before it is asked rather than after the owner is confused by it.

## A Valid Question

A question is valid when every line holds:

- two to four substantive options, each with a specific trade-off
- exactly one marked Recommended, in its label
- exactly one decision addressed
- options grounded in what the repository actually contains
- the native tool used when available
- the write-in and the chat option both present

## An Invalid Question

It is invalid when it presents no real choice, bundles unrelated decisions, invents options, drops either standing
option, or leaves the recommendation to be inferred from ordering.

Each of those returns an answer, which is why none of them announces itself. A bundled question returns one selection
covering two decisions, and the second is then recorded as decided without ever being asked.
