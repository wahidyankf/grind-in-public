# Testing Standards

Test boundaries, targets, and the coverage floor are owned by [quality gates](../../quality-gates.md) and the
[testing policy](../../testing-policy.md).

- [Meaningful Coverage](meaningful-coverage.md) — coverage only for authored executable code a reliable instrument
  measures, and no line target for end-to-end, declarative, or shell code.
